# NovaFolio — Crypto Portfolio Simulator (Firefox Extension)

یک افزونه شبیه‌ساز سبد دارایی رمزارز (Portfolio Simulator) با طراحی مستقل برای مرورگر **Firefox**.

## امکانات
- **صفحه قفل با رمز عبور:** ورود با رمز عبور اختصاصی (قابل تغییر از بخش تنظیمات).
- **دریافت قیمت لحظه‌ای (Live Market Prices):** اتصال مستقیم به وب‌سرویس عمومی Binance (`api.binance.com`) و بروزرسانی خودکار هر ۱۵ ثانیه (به همراه درصد تغییرات ۲۴ ساعته).
- **۹ ارز دیجیتال پرطرفدار:**
  1. **BTC** (Bitcoin)
  2. **ETH** (Ethereum)
  3. **USDT** (Tether)
  4. **BNB** (BNB)
  5. **SOL** (Solana)
  6. **XRP** (Ripple)
  7. **ADA** (Cardano)
  8. **DOGE** (Dogecoin)
  9. **TRX** (TRON)
- **مدیریت چند کیف‌پول / پرتفوی (Multi-Portfolio):** امکان افزودن، حذف و جابه‌جایی بین بی‌نهایت پرتفوی مجزا.
- **ویرایش موجودی‌ها در تنظیمات:** با کلیک روی آیکون چرخ‌دنده (یا کلیک مستقیم روی هر ارز در لیست) می‌توانید مقدار هر رمزارز را تغییر دهید تا ارزش کل به دلار بر اساس قیمت لحظه‌ای محاسبه شود.
- **پشتیبانی از Popup و Sidebar فایرفاکس.**

## نحوه نصب در Firefox
1. مرورگر Firefox را باز کنید و در نوار آدرس عبارت زیر را وارد کنید:
   ```
   about:debugging#/runtime/this-firefox
   ```
2. روی دکمه **Load Temporary Add-on...** کلیک کنید.
3. وارد پوشه `nova-portfolio-extension` شوید و فایل `manifest.json` را انتخاب کنید.
4. آیکون **NovaFolio** به نوار ابزار فایرفاکس (و همچنین بخش Sidebar) اضافه می‌شود.
